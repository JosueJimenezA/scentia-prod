catalogo.py : es un script auxiliar que ayuda a obtener la lista de URLs de diseñadores desde el índice maestro de Fragrantica. Contiene funciones para simular un desplazamiento gradual y natural hacia abajo en la página web, así como para extraer los enlaces de los diseñadores. Además, incluye una función principal que configura el navegador y obtiene las URLs de los perfumes buscando a partir de la sección de diseñadores de la página de fragrantica, guardándolas en un archivo CSV. Sirve como insumo al scraper principal para la fase de ingesta de datos.
debug_page.html : es el archivo HTML crudo de la fuente a scrapear, este sirve de base para encontrar las etiquetas o selectores para diseñar el scraper-
flujo_busqueda.txt : contiene el flujo que se sigue para la la actualización de la base de datos de perfumes, desde el frontend, valida primero que el perfume a añadir no exista por nombre y luego que no exista por url, casi garantizando que no se duplique la información.
html_scraper: es el archivo que extrae el codigo fuente de la fuente, devuelve el archivo debug_page.html
